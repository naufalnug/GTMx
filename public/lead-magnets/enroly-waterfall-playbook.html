Waterfall

One cascade routes every UK university

First match wins. CAS/visa/compliance keywords go first, then international admissions/conversion keywords, then agent-network keywords, then every remaining in-TAM university.

first match wins 
1. IF job_keyword_class = cas_compliance (CAS, visa, sponsor licence, immigration compliance, BCA) -> Tier 1 - Sponsor Licence Risk Brief (They are already staffing the compliance gap CAS Shield is built for.)
2. IF job_keyword_class = intl_admissions (international admissions, conversion, offer holders, enrolment ops) -> Tier 2 - Offer-to-Arrival Progression Map (They are hiring to move applicants, not just to file documents.)
3. IF job_keyword_class = agent_network (education agent, agent partnerships, agent compliance) -> Tier 3 - Agent Visibility Pack (They need one portal and one view across agents.)
4. IF in_tam and none of the above -> Catch-all - 80% Admin Cut Playbook (Still UK HE with international intake; lead with the published admin-time cut.)
