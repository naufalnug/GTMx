Waterfall

One cascade routes every semiconductor manufacturer

First match wins. Planning and wafer-start keywords go first, then toolset scheduling keywords, then timelink and factory-automation keywords, then every remaining in-TAM manufacturer.

first match wins 
1. IF already_customer = true -> Exclude (Already a customer. Named case-study logos on flexciton.com are not enough to exclude every site.)
2. IF job_keyword_class = planning_capacity -> Tier 1 (Open req names production planner, capacity planner, wafer starts, industrial engineer, production control, WIP management, capacity modeling, or starts planning. Keyword class is estimated GTMx taxonomy, not a Flexciton site field.)
3. IF job_keyword_class = toolset_scheduling -> Tier 2 (Open req names dispatcher, scheduler, batching, cycle time, toolset, photolithography scheduling, diffusion scheduling, or reticle, and no planning_capacity keyword. Class estimated.)
4. IF job_keyword_class = timelink_automation -> Tier 3 (Open req names timelink, Q-time, QTimer, factory automation, MES, CIM, digital twin, Industry 4.0, autonomous factory, or fab-wide scheduling, and no planning_capacity or toolset_scheduling keyword. Class estimated.)
5. IF in_tam = true -> Catch-all (Remaining semiconductor manufacturers LinkedIn already lists: visible Ops Manager / Production Director / Fab Manager / Industrial Engineer, and none of the keywords above)

Planning hiring gets a Capacity Commit Brief. Dispatch hiring gets a Toolset KPI Gap Brief. Timelink or MES hiring gets a Fab-Wide Flow Brief. The rest get the Autonomous Fab Playbook, with cost versus throughput as the A/B.
