Campaign engine

One signal. One route. Five offers.

Flexciton is autonomous production planning and scheduling software for semiconductor manufacturing. Flex Planner uses dynamic capacity modeling and mathematical optimization to turn customer orders and ERP targets into daily wafer start plans, updated every 45 minutes, and to align WIP flow over the next 4 weeks with due dates. Spotlight turns morning meetings into high-impact actions. Flex Local is the local toolset scheduler: set objectives, not parameters, and it balances throughput, cycle time, batching, and reticle moves without rule tuning. Runway turns those schedules into a live load / unload / changeover checklist. Flex Global connects local schedulers, manages timelink constraints, plans changeover campaigns, and shows fab congestion on a heatmap. Homepage customers include Seagate Technology, Renesas, and Microchip. Intel partnership announced on their site. Typical full deployment 6-12 months. 25+ fabs. 40+ experts dedicated to semiconductor manufacturing optimization. 100+ technical publications. 3 patents in mathematical optimization.

Waterfall

One cascade routes every semiconductor fab

First match wins. Planning / wafer-starts keywords go first, then local scheduling / industrial-engineering keywords, then timelink / WIP / fab-wide keywords, then every remaining in-TAM semiconductor manufacturer.

first match wins 
1. IF already_customer = true -> Exclude (Already a customer. Named case-study logos on flexciton.com are not enough to exclude every site.)
2. IF job_keyword_class = planning_capacity -> Tier 1 (Open req names production planning, wafer starts, capacity planning, APS, advanced planning, on-time delivery, WIP planning, or production control. Keyword class is estimated GTMx taxonomy, not a Flexciton site field.)
3. IF job_keyword_class = toolset_scheduling -> Tier 2 (Open req names industrial engineer, dispatch, toolset scheduler, photolithography, photo area, reticle, batching, recipe enablement, or shop-floor scheduling, and no planning_capacity keyword. Class estimated.)
4. IF job_keyword_class = timelink_wip -> Tier 3 (Open req names timelink, QTimer, queue timer, diffusion, furnace batch, factory automation, MES dispatch integration, or fab-wide WIP, and no planning_capacity or toolset_scheduling keyword. Class estimated.)
5. IF in_tam = true -> Catch-all (Remaining semiconductor manufacturers LinkedIn already lists: visible operations manager / production director / manufacturing director / fab manager, and none of the keywords above)
