02

The routing

First match wins. Existing customers and enterprise-TMS users are excluded up front, so per-BOL pricing is only pitched where it holds up.

first match wins 
1. IF Portal link on *.shipprimus.com -> Exclude: existing customer (Returned to ShipPrimus as a reference list instead of emailed.)
2. IF Portal on an enterprise TMS (MercuryGate, McLeod, Revenova, Turvo) -> Exclude (High BOL volume breaks per-BOL economics, and switching is a multi-quarter project.)
3. IF Portal on a seat-priced SMB TMS (Tai, Aljex, 3PL Systems, Rose Rocket, AscendTMS, FreightPOP) -> Tier 1: Paying a seat-priced TMS (Already pays for the category. The pitch is usage pricing with the break-even stated.)
4. IF LTL or parcel listed AND quote by form, email or phone -> Tier 2: Quoting LTL and parcel by hand (Every quote is built by hand, and the branded shipper portal answers it directly.)
5. IF Open quoting, tracking or billing role >= 1 -> Tier 3: Hiring people to do TMS work (They're paying a salary for work software does. The posting is the evidence.)
6. IF Broker authority granted within 18 months -> Tier 4: New brokerage, first TMS (Choosing a first TMS, with no volume yet to justify a fixed annual contract.)
7. IF Everything else past the gate -> Tier 5: Catch-all (Category fit only. A free lane test carries the offer.)
