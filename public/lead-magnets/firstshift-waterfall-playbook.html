02

The routing

First match wins. A named tool always beats a hiring signal, so no account lands in two tiers, and the catch-all covers the rest.

first match wins 
1. IF SAP APO, Oracle Demantra or another legacy on-prem planning tool is named -> Tier 1: Planning tool on a sunset clock (A forced decision with a date on it, and the default path takes 12 to 18 months)
2. IF SAP IBP, Kinaxis, o9, Blue Yonder, Logility, Anaplan or a point tool is named -> Tier 2: Platform in place, planners still in Excel (They already pay for the category; Canvas sits on top instead of replacing it)
3. IF Open planner role in the last 90 days, Excel required, no tool named -> Tier 3: Hiring planners to run spreadsheets (They are buying headcount to do work the software should carry)
4. IF 2 or more planners on LinkedIn, no platform listed -> Tier 4: Planning team, no platform (The forecast lives in spreadsheets and the error lives in inventory)
5. IF Everything else inside the gate -> Tier 5: Catch-all (100% coverage: every qualified account gets the S&OP-speed conversation)
