Waterfall

One cascade routes every engineering org

First match wins. Mainframe keywords go first, then active migration keywords, then AI-coding-tool keywords, then every remaining in-TAM engineering org.

first match wins 
1. IF already_customer = true -> Exclude (Already a customer)
2. IF job_keyword_class = mainframe -> Tier 1 (Open req names COBOL, JCL, PL/I, CICS, DB2, IMS, or mainframe)
3. IF job_keyword_class = migration -> Tier 2 (Open req names legacy .NET, Java app-server, monolith-to-microservices, or API-first / headless)
4. IF job_keyword_class = ai_coding -> Tier 3 (Open req names Copilot, Cursor, Claude Code, MCP, or AI coding assistant)
5. IF in_tam = true -> Catch-all (Remaining engineering organizations)

Tiers

Each job keyword gets a different first offer

Mainframe hiring gets a parity brief. Stack-migration hiring gets a pattern map. Copilot/Cursor hiring gets a context-gap one-pager. The rest get an AI-readiness assessment snapshot.
