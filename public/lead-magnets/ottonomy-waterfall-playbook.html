Waterfall

One cascade routes every facility operator

First match wins. Ten-plus site networks go first, then multi-building campuses, then two-building A-to-B pairs, then every remaining in-TAM Place.

first match wins 
1. IF already_customer = true -> Exclude (Already a customer)
2. IF location_count >= 10 -> Tier 1 (Multi-site network / fleet orchestration)
3. IF location_count >= 3 -> Tier 2 (Multi-building campus)
4. IF location_count = 2 -> Tier 3 (Indoor-outdoor pair)
5. IF location_count >= 1 and in_tam = true -> Catch-all (Remaining facility operators)

Tiers

Each campus count gets a different first offer

Networks get a multi-site movement teardown. Campuses get an indoor-outdoor brief. Pairs get an A-to-B pilot map. The rest get a workforce-gap pilot one-pager.

Scale / cut rules

1 positive reply per 150 contacts Perfect. Scale that tier. Keep the winning time, cost, or custody variant.
1 per 300 Good. Let it run. Do not mix a non-facility TAM into this waterfall.
1 per 450-500 Borderline. Swap only the magnet or the first-line site name. Do not change the route.
Worse than 1 per 500, or reply rate under 1% after 1,500+ sends Cut that copy variant. Keep the exclusive waterfall.
