One signal. One route. Five offers.

HitHorizons (hithorizons.com) is a European company-data SaaS powered by FinStat, s.r.o. (Bratislava). It provides a database of 80M+ / 80+ million companies across 50 European countries with 100+ data points per company, delivered via HitHorizons Screener (filter + CSV export up to 50,000 records) and HitHorizons API: Sales & Marketing Data API (CRM autofill from company name, national ID, or VAT; sales, employees, industry/SIC, LinkedIn/Facebook links), Screener API (lead import by country/region/industry/SIC/employees/sales filters), and Invoicing Data API (local legal name, address, VAT for ERP billing — selected countries). Public use cases name CRM enrichment (Pipedrive, Salesforce, MS Dynamics, HubSpot), ERP (Oracle, SAP), B2B ecommerce, and BI dashboards — without integrating dozens of local country APIs. Microsoft Dynamics 365 marketplace extension (finstatsro.hithorizons_dynamics_extend) adds autofill + Screener inside Dynamics. FinStat has served over 4,000 customers since 2013 (Dynamics marketplace copy). Paulina Banska is Head of Sales (paulina.banska@hithorizons.com).

Waterfall

One cascade routes every in-TAM CRM, SaaS, and outbound account selling into Europe

First match wins. Named EU company-data competitors first, then CRM with European TAM and no HitHorizons, then outbound / lead-gen into Europe, then every remaining in-TAM account.

first match wins 
1. IF already_customer = true -> Exclude (Already a HitHorizons / FinStat customer. Suppress when Paulina's team can share a list; public case quotes alone are not a franchise-wide exclude.)
2. IF in_tam AND eu_company_data_stack = competitor_eu_data (Creditsafe, Bureau van Dijk / Orbis / Moody's, Dun & Bradstreet, Kompass, Europages, North Data, or adjacent named EU firmographic / company-data vendor) AND not already_customer -> Tier 1 - EU Data Switch Brief (They already pay for European company data. Strongest switch intent for HitHorizons one-API coverage of 80M+ companies / 50 countries / 100+ data points instead of stitching local registers or a legacy bureau stack.)
3. IF in_tam AND eu_company_data_stack = crm_eu_gap (Dynamics 365, Salesforce, HubSpot, or Pipedrive detected + EU HQ or EU-selling ICP; no Tier-1 competitor; no HitHorizons) AND not already_customer -> Tier 2 - CRM Enrichment API Brief (CRM is live and Europe is in the ICP, but firmographics are incomplete. Maps to Sales & Marketing Data API autofill (name / national ID / VAT → address, industry, SIC, sales, employees, social links) and the Dynamics 365 marketplace extension when crm_stack = Dynamics.)
4. IF in_tam AND eu_company_data_stack = outbound_eu (Apollo / Clay / Instantly / Sales Nav heavy EU targeting OR open SDR/BDR / Sales Ops EU hiring; no Tier 1–2) AND not already_customer -> Tier 3 - Screener Lead-List Brief (They are actively building European outbound lists. Maps to HitHorizons Screener: 18 filters, sort by sales/employees, CSV export up to 50,000 records, plus Screener API import into their tools.)
5. IF in_tam AND none of the above -> Catch-all - European Company Data Playbook (Still in TAM (B2B teams selling into or operating across Europe). Softest CTA around one European company-data layer for CRM, lead gen, and invoicing. Mandatory 100% coverage.)
