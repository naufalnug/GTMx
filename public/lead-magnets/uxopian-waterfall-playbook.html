Signal

The signal is which content stack they already run

BuiltWith + LinkedIn Jobs + a careers/site scrape already names a competing document viewer/SDK, a legacy ECM (Documentum, FileNet, Alfresco, SharePoint Server…), content/ECM hiring with no stack match, or none of those. That content_stack_state is stronger than a title guess and cheap to collect.

Waterfall

One cascade routes every in-TAM document buyer

First match wins. Competing viewer/SDK first, then legacy ECM detected, then content/ECM hiring with no Tier 1–2 stack, then every remaining in-TAM regulated or document-heavy buyer.

first match wins 
1. IF in_tam AND competitor_viewer_detected = true (BuiltWith / careers / site names Apryse, PDFTron, Nutrient, PSPDFKit, Foxit, Adobe Embed/PDF Services, Aspose, Box View, or equivalent document viewer/SDK) AND not already_customer -> Tier 1 - Content API Switch Brief (They already buy document viewing/SDK capacity and still stitch storage, migration, and AI across vendors. Strongest intent for Uxopian’s white-label Content API Platform (FlowerDocs + ARender + Fast2 + AI under one OEM contract). Proof path: CGI Trade360 in 9 months; Content API page claims weeks-to-ship vs DIY $200K–$500K / 6–12 months.)
2. IF in_tam AND legacy_ecm_detected = true (Documentum, IBM FileNet, Alfresco, Nuxeo, OpenText Content Server, SharePoint Server / on-prem SharePoint as ECM) AND no Tier-1 competing viewer/SDK AND not already_customer -> Tier 2 - Modernize-Without-Rip Brief (They run a legacy repository the business still depends on — pain is AI, governance, and multi-format viewing without a rip-and-replace programme. Maps to ARender overlay + Uxopian AI on existing repos + Fast2 when data must move. Homepage: Modernize Legacy ECMs; blog: modernize without replatforming; 50B+ docs migrated.)
3. IF in_tam AND content_hiring_open = true (ECM admin, Documentum/FileNet/Alfresco specialist, records manager, content platform / document engineer, IDP / document-AI engineer) AND no Tier 1–2 stack match AND not already_customer -> Tier 3 - AI-on-Your-Repos Brief (They are buying content capacity via hiring — soft high-intent before catch-all. Maps to Uxopian AI on existing repositories (Zero-Scroll Summaries, extraction, Ask Repository) plus optional FlowerDocs/ARender without forcing a platform swap on Day 0.)
4. IF in_tam AND none of the above -> Catch-all - Content Modernization Playbook (Still in TAM (document-heavy regulated or SaaS/BPO buyers). Soft CTA around governed content, sovereignty, and a free first conversation. Mandatory 100% coverage.)
