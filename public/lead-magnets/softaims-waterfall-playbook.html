Waterfall

One cascade routes every in-TAM startup and scaleup

First match wins. Software IC hiring first, then product/design/QA without eng ICs, then technical-leadership-only hiring, then every remaining in-TAM company Softaims sells into.

first match wins 
1. IF in_tam AND eng_ic_role_open = true (Full-Stack, Backend, Frontend, Mobile, Platform, DevOps, AI/ML Engineer) AND not already_customer -> Tier 1 - Dedicated Engineers Brief (They are already staffing engineers. Strongest intent for Softaims dedicated / staff-aug talent using published proof (500+ experts, timezone-aligned, 0% equity positioning, 230+ products).)
2. IF in_tam AND product_design_qa_role_open = true (Product Manager, Product Designer, UI/UX, QA) AND eng_ic_role_open = false AND not already_customer -> Tier 2 - Product Squad Brief (They are staffing product/design/QA without matching eng ICs — classic gap Softaims fills with a delivery squad (MVP, SaaS, mobile, integrations) rather than a body-shop lecture.)
3. IF in_tam AND leadership_role_open = true (CTO, VP Engineering, Head of Engineering, Tech Lead) AND no Tier 1-2 match AND not already_customer -> Tier 3 - Technical Co-Founder Brief (They are hiring technical leadership. Maps to Softaims 'technical co-founders with 0% equity' positioning — bridge the gap while ownership stays with the client.)
4. IF in_tam AND none of the above -> Catch-all - Softaims Build Playbook (Still in TAM (startups/scaleups Softaims serves across named verticals). Softest CTA around practical build options, dedicated teams, and MVP-to-scale paths. Mandatory 100% coverage.)
