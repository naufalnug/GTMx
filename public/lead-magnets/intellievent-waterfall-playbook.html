Signal

The signal is which rental OS they already run

BuiltWith, careers, job ads, and partner/tech mentions already show Rentman, Current RMS / OnRent Events, Booqable, Goodshuffle Pro, Point of Rental, or spreadsheet / QuickBooks-only ops. That competitor_rental_os is stronger than a title guess and cheap to collect.

strongest signal
01

Apollo / LinkedIn Sales Nav (event rental, party rental, AV hire, production rental, tent & structure, lighting, staging, venue AV) plus industry directories (ARA member lists, Eventective / wedding-vendor rental categories, local chamber rental categories) are the TAM IntelliEvent already sells into. Exact public TAM account count is not published on intellievent.com; treat size as estimated (see intellievent-magnet-flags.txt) and keep each launch tier >=~1,500 contacts where possible.

02

The same BuiltWith + careers + job-ad scrape returns competitor_rental_os: Rentman / Current RMS (OnRent Events); other cloud rental OS (Booqable, Goodshuffle Pro, Point of Rental, EZRentOut, HireTrack, MCS, RigER, EventBound, Stagera, RentalHQ, adjacent); spreadsheet / QuickBooks-centric ops (job ads naming Excel inventory, Google Sheets dispatch, QuickBooks as primary ops without a rental OS brand); or none — enough to route without a second expensive enrichment product.

03

The ladder maps to live IntelliEvent Lightning positioning (sales & quoting, inventory & warehouse, logistics & routing, labor scheduling + mobile, QuickBooks / Google Calendar / Avalara integrations, 250+ reports) plus public proof language (1,000+ customers; Expert'ease, Crescent Event Productions, AVT Productions, AVFX, Nationwide, On Services).

04

Segment (party vs AV vs tent vs lighting vs venue vs staging) and region (US / UK / EU / ROW) are scrape filters and merge tags, not a second waterfall. Apollo is email last after the account is routed.

Waterfall

One cascade routes every in-TAM event rental and AV account

First match wins. Rentman / Current RMS first, then other cloud rental OS, then spreadsheet / QuickBooks-centric ops, then every remaining party, tent, AV, and production rental company.

first match wins 
1. IF in_tam AND competitor_rental_os_family = rentman_current (Rentman, Current RMS, OnRent Events / OnRent) AND not already_customer -> Tier 1 - Rentman / Current RMS Switch + Migration Brief (They already pay for the dominant AV / production rental OS. Strongest switch intent for IntelliEvent Lightning quote-to-invoice + warehouse + labor with a migration magnet.)
2. IF in_tam AND competitor_rental_os_family = other_cloud_rental_os (Booqable, Goodshuffle Pro, Point of Rental, EZRentOut, HireTrack, MCS, RigER, EventBound, Stagera, RentalHQ, adjacent) AND not already_customer -> Tier 2 - Lightning Feature Comparison (They run a competing cloud rental OS. 3. IF in_tam AND competitor_rental_os_family = spreadsheet_qb_ops (job ads / site language shows Excel / Google Sheets / Access inventory or QuickBooks-as-primary ops without a rental OS brand) AND not already_customer -> Tier 3 - Spreadsheet-to-Lightning Ops Brief (Visible spreadsheet / QB ops without a rental OS. Maps to Lightning inventory + warehouse + labor replacing manual shortage and crew chaos.)
4. IF in_tam AND none of the above -> Catch-all - IntelliEvent Lightning Playbook (Still in TAM (event rental / AV / party / tent / staging / venue operators). Softest CTA around quote-to-invoice clarity, inventory accuracy, and labor visibility. Mandatory 100% coverage.)
