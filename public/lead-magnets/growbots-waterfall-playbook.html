Signal

The signal is how they already pay for outbound

SDR job posts, DIY sequencer tech (Instantly, Lemlist, Smartlead, Apollo), and recent funding without an outbound team are public. That outbound_mode is stronger than a title guess and cheap to collect from Jobs, BuiltWith, and Crunchbase in one pull.

strongest signal
01

An open SDR, BDR, or outbound AE role means the company is already budgeting headcount to create pipeline. That is the strongest, most time-bound intent for Concierge replacement.

02

DIY sequencer stacks (Instantly, Lemlist, Smartlead, Apollo sequences, Mailshake, Woodpecker) show up in BuiltWith, job posts, and careers pages, so the pain of list building, copy, and deliverability is observable without paid enrichment.

03

A recent Crunchbase funding round with no SDR hire and no sequencer stack is a public growth bet that still needs meetings. Concierge turns that capital into a booked calendar.

04

All three signals ride on free or cheap sources (LinkedIn Jobs / Indeed, BuiltWith, Crunchbase / Apollo firmographics), so the TAM and the routing signal come in the same pull.

Waterfall

First match wins, top to bottom, catch-all underneath

Exclude current Growbots customers, then route: SDR hiring, then DIY sequencer stack, then recent funding with no outbound team, then every remaining B2B SMB in the TAM. Each account lands in exactly one campaign.

first match wins 
1. IF growbots_customer = true -> Exclude (Already a Growbots account. Route to Customer Success, not cold outbound.)
2. IF sdr_job_posted_60d = true -> Tier 1: SDR headcount (They are hiring humans to create pipeline. Strongest, most time-bound intent for Concierge replacement.)
3. IF ELSE IF diy_tool_detected in {Instantly, Lemlist, Smartlead, Apollo, Outreach, Salesloft, Mailshake, Woodpecker, Reply.io} -> Tier 2: DIY sequencer stack (They already bought tools and still own list building, copy, and deliverability. Concierge replaces the ops load.)
4. IF ELSE IF funding_date_12m = true AND has_outbound_team = false -> Tier 3: Post-funding pipeline gap (Capital is in, meetings are not. Concierge turns the round into a booked calendar without a 3-month hire.)
5. IF ELSE (every remaining B2B SMB in the TAM) -> Tier 4: Catch-all, pipeline playbook (Covers 100% of the TAM. Broad Concierge plus 3,000+ customer proof, softest ask.)
