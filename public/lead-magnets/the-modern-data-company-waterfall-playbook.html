Waterfall

One cascade routes every warehouse account

First match wins. Catalog and governance point solutions go first, then semantic/metrics layers, then pipeline-per-use-case tooling, then every remaining warehouse.

3. IF semantic_tool != none -> Tier 2 (Semantic / metrics layer)
4. IF pipeline_tool != none -> Tier 3 (Pipeline-per-use-case)
5. IF warehouse in {Snowflake, Databricks, BigQuery} -> Catch-all (Missing activation layer)
