Signal

The signal is a supported ERP plus a visible manual-shipping cost

CloudLeap only wins where it has a pre-built ERP connector, so the ERP is the gate. Inside that gate, job posts, freight pages and storefront detection show how much the shipper is paying for disconnected, carrier-by-carrier shipping.

strongest signal
01

CloudLeap's pre-built connectors cover a specific ERP list, and ERP usage is reliably detectable from technographic data, job posts and ERP marketplace / user-group listings, so the gate is observable.

02

Shipping, warehouse and logistics job posts routinely name the tools the hire will use (UPS WorldShip, FedEx Ship Manager, the ERP), exposing manual, carrier-by-carrier shipping in the shipper's own words.

03

Freight / LTL pages, shipping policies and 'we ship via' carrier mentions on a shipper's site show whether it runs both parcel and LTL, which is exactly where one multi-mode platform replaces several.

04

A B2C storefront (Shopify, BigCommerce, Magento, ERP web store) on a B2B distributor or manufacturer is detectable with BuiltWith and signals the order-volume pain CloudLeap's click-and-ship proof addresses.

Waterfall

First match wins, top to bottom, catch-all underneath

Exclude existing CloudLeap customers, implementation partners and ERP vendors, then route: shipping job posts naming a desktop carrier tool, then parcel-plus-LTL shippers, then B2B shippers with a B2C storefront, then every other supported-ERP shipper. Each account lands in exactly one campaign.

3. IF erp_detected NOT in CloudLeap connector list (Infor (LN, M3, SyteLine/CSI, CloudSuite Distribution, WMS), SAP (Business One, ByDesign, ECC, S/4HANA), Oracle (NetSuite, EBS, Fusion Cloud, OTM, JD Edwards), Microsoft Dynamics 365 (F&O, Business Central), Epicor (Kinetic, P21), Sage (Intacct, X3), Acumatica, IFS, Rubicon, IBM AS/400) -> Exclude (out of TAM) (No pre-built connector, so the core value prop does not apply.)
4. IF shipping_job_posted_60d = true AND shipping_tool_named in {UPS WorldShip, FedEx Ship Manager, other single-carrier desktop tool} -> Tier 1: Desktop carrier tools (The shipper is hiring people to run carrier-by-carrier tools next to the ERP. Strongest, most time-bound, costed pain.)
5. IF ELSE IF ships_ltl = true AND ships_parcel = true -> Tier 2: Parcel + LTL in one place (Two modes usually means two workflows. Piyovi rates, books and tracks parcel and LTL from one platform and audits carrier invoices.)
6. IF ELSE IF b2c_storefront_detected = true -> Tier 3: B2C orders on a B2B shipping desk (Consumer orders multiply small-parcel volume. Click-and-ship and per-order time savings are the proof.)
7. IF ELSE (every remaining shipper on a supported ERP) -> Tier 4: Catch-all, ERP-native multi-carrier shipping (Covers 100% of the TAM. Broad connector, carrier-coverage and implementation angle, softest ask.)
