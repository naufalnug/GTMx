Waterfall

One cascade routes every Walmart 1P supplier and 3P marketplace brand

First match wins. Ads or a named competitor goes first, then Amazon A+ with no Walmart BTF, then a thin Walmart PDP, then every remaining in-TAM seller.

first match wins 
1. IF already_customer = true -> Exclude (Already a customer)
2. IF in_tam AND catalog_state = ads_or_competitor -> Tier 1 - Algorithm Switch Brief (They already pay for Walmart ads or a named listing/ads/PIM competitor. Strongest intent for an algorithm switch when traffic hits a catalog that cannot convert.)
3. IF in_tam AND catalog_state = amazon_aplus_no_walmart_btf -> Tier 2 - A+ to Walmart BTF Brief (Amazon A+ / Premium A+ is live and the Walmart PDP has no BTF / Rich Media / EBC. Pain is porting content, not education.)
4. IF in_tam AND catalog_state = walmart_thin_pdp -> Tier 3 - Spec 5.0 Listing Score Brief (The Walmart listing is live and thin (short copy, missing Item Spec 5.0 / Omni Spec 5.0 attributes). Maps to Optiwise listing-score and backend-issue offer.)
5. IF in_tam AND none of the above -> Catch-all - Digital Pen Playbook (Still in TAM (Walmart 1P suppliers, 3P marketplace brands, Amazon brands expanding to Walmart). Softest CTA, broadest copy, mandatory 100% coverage.)

Ads or a competitor gets an Algorithm Switch Brief. Amazon A+ with no Walmart BTF gets an A+ to Walmart BTF Brief. A thin Walmart PDP gets a Spec 5.0 Listing Score Brief. The rest get the Digital Pen Playbook.
