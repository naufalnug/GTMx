Cupix AI turns that video into a 4D digital twin they can measure, annotate, and compare against BIM over time. Waterfall

One cascade routes every construction firm

First match wins. BIM/VDC/progress keywords go first, then reality-capture keywords, then facilities/handover keywords, then every remaining in-TAM construction firm.

first match wins 
1. IF already_customer = true -> Exclude (Already a customer. Named case-study logos on cupix.com are not enough to exclude every office.)
2. IF job_keyword_class = bim_vdc -> Tier 1 (Open req names BIM, VDC, digital twin, progress tracking, 4D schedule, model manager, look-ahead, or as-built verification. Keyword class is estimated GTMx taxonomy, not a Cupix site field.)
3. IF job_keyword_class = reality_capture -> Tier 2 (Open req names reality capture, laser scan, LiDAR, drone, photogrammetry, Matterport, OpenSpace, StructionSite, HoloBuilder, 360 camera, or point cloud, and no bim_vdc keyword. Class estimated.)
4. IF job_keyword_class = facilities_ops -> Tier 3 (Open req names facilities manager, building operations, handover, turnover package, as-built documentation, owner's rep, CAFM, IWMS, or facility digital twin, and no bim_vdc or reality_capture keyword. Class estimated.)
5. IF in_tam = true -> Catch-all (Remaining construction firms LinkedIn already lists: visible PM / Owner / superintendent / director of construction, and none of the keywords above)
